The project asks whether Transformers that route tokens to experts (SUT, Mixture-of-Modules) or reuse one block recurrently (Universal Transformer, SUT) handle compositional logical inference better than a plain dense Transformer of the same width and depth. The pilot gave a clear but unexpected answer at this budget: the dense model is best, SUT with the released code is barely above the majority class, and MoM sits exactly at the majority class. The first half of the talk introduces the pilot; the second half opens up the trained models to explain why.
