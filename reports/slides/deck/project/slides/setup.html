SUT variants: released MIM sign, paper MIM sign, fixed depth (no halting). Also run: load balancing instead of MIM, and E = 1.

The pilot is a controlled comparison: every model sees the same data, input format, width, number of block applications, optimiser, schedule and model-selection rule, so differences come from the architecture. It is a CPU pilot: 3,000 steps at batch 64 is about 1.6 passes over the training set, far from convergence. To check whether budget alone explains the gap, the SUT was also trained for 9,000 steps. MoM follows the authors' two-phase recipe: a dense GPT-2-style donor trained for 10,000 steps, converted, then trained again. Parameter counts differ because shared blocks (UT, SUT) reuse weights and experts add weights; SUT has far fewer parameters than Dense but the same per-token compute budget of six block applications. Before training, 66 tests passed, including 10 parity tests that match outputs and gradients of the authors' SUT and MoM code.
